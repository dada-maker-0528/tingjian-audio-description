## 同事联测顺序

1. 首页 → 创建新视频 → 使用演示视频 → 人物介绍 → 首个场景。
2. 播放、暂停、重听；旁白助手输入“旁白慢一点” → 确认执行 → 试听新版 → 满意并继续。
3. 确认前 3 个场景，再生成整片。检查 34、89、110 秒附近的后续旁白仍存在。
4. 加入我的视频 → 打开我的视频 → 重开作品 → 刷新重开 → 查看版本历史。
5. 上传带测试标识的视频，走人物、首场景、连续场景、整片、保存。不要修改或删除其他人的作品。
6. 使用实际比赛电脑、麦克风与音箱复核语音和听感；读屏需单独验证。

反馈：浏览器与设备 / 素材 / 步骤 / 预期与实际 / 截图或录屏。

## 本轮修复

| 问题 | 处理与证据 |
| --- | --- |
| 首段修改导致后续旁白缺失 | 默认音色使用服务器完整原版，不上传首段预览；自定义音轨校验后续旁白覆盖。默认音色旧作品打开时恢复缺失片段，保留修改和历史。线上五段旁白均非静音；旧测试作品 12.2 秒后的音频与原版 PCM 逐采样最大差为 0。 |
| 角色结构/依据失败 | 明确采样编号结构，对可修复格式错误最多尝试 3 次，不能返回空列表伪装成功。新上传测试片无需人工重试即通过。 |
| 整片短句反复超长 | 两次精简仍超长时，仅允许使用符合预算的已有完整场景标题，并记录省略内容，再校验实际音频时长。此前失败的作品重试后生成 11 条旁白。 |
| 真实结果误标“模拟” | 改为“新配音已就绪/查看修改结果”。 |
| 角色修改按钮无作用 | 移除误导入口；实际支持的旁白调整仍通过助手进行。 |
| 保存后找不到作品 | 首页改称“示例视频”；完成页增加视频库入口；回看页返回正确的视频库。刷新后保留同一新版音轨。 |
| 修改等待长 | 默认音轨不再从浏览器上传；显示处理耗时。本次首段调速约 6.0 秒出结果，请求体 431 字节，属于单次测试值。 |
| 小屏确认按钮隐藏 | 确认移至播放器后、旁白文本前；1366×768 显示完整按钮。阶段名称统一，旁白文本默认收起。 |
| 重开重复合成/媒体等待 | 优先读取已生成的配音；媒体超时调整到 30 秒；准备完成前禁用播放；主动暂停或打开历史不再误报播放失败。 |
| 链接入口误导 | 标明“示例链接”，自己的视频需上传文件；未宣称支持任意网站解析。 |

- `npm test`：90 项通过；后端 AI/脚本检查：22 项通过；Node 构建通过。
