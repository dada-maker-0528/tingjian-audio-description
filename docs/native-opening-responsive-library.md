# 听见：原生首屏、宽屏适配与片库语音

本次将已上线的界面修改移植到仓库现有 Node 应用分支，保留该分支的业务流程。它是本次改动的源码提交，不是包含运行数据和媒体的整机快照。

- 首屏标题、说明和入口使用真实文字与按钮；眼纹、声波为独立 SVG，银色纹理为单独背景素材。标题字体采用 Noto Serif SC 子集，附 OFL 许可。
- 主入口为“进入听见”；移除“向下探索”按钮与鼠标图标。
- 16:9 与 22:4（5.5:1）分别布局，覆盖视频库、制作流程、播放器和弹窗。长内容允许纵向滚动。
- 仅按明确的撤下项目 ID 清理片库与旧浏览器记录，保留其他上传及用户保存版本。
- 数量、编号、搜索无结果与数字快捷键提示根据当前列表生成；语音缓存以实际文本和音色区分。

此前公网验证覆盖 1280×720、1920×1080、2200×400、3300×600；片库简短引导、详细引导与搜索空结果的三段豆包音频已实际生成并成功解码。首屏与参考图仍有字形、曲线和光晕差异，不声称像素完全一致。

线上测试项目使用既有归档字段撤下，用户项目数据、素材、语音缓存和部署凭据不纳入此次 Git 提交。原始工作区内其他未提交改动保持原样。

本分支验证：`npm test` 全部95项通过，`npm run build`通过；独立浏览器在1920×1080与2200×400下的首屏、片库过滤、搜索与语音提示检查通过，页面脚本异常为0。
