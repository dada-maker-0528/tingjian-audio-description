# 听见：无视觉操作与真实口述影像实施计划

状态：已授权实施。自动检查、真实模型验证、读屏与用户验收分别记录于 `验证记录.md`，不得相互替代。

## 1. 最终目标与边界

用户不看屏幕、不靠旁人提示，也能独立完成选择视频、认识人物、试听、修改、完整收听、保存和再次播放。

- 首轮为 Windows 桌面网页、Chrome、键盘和 NVDA 中文读屏；手机另行验收。
- 工作分支：`codex/aimedia-frontend-adaptation`。沿用新前端，选择性复用本地影石处理模块；不修改原目录。
- 本地运行仍可能调用云端模型。演示素材、预设结果、真实分析必须明确区分。
- 不包含部署、微信群发送、公开发布用户视频或任意平台链接解析。
- 源代码迁移以 `migration-baseline.json` 的提交与逐文件摘要为准，不迁移凭据和用户媒体。

主流程：首页 → 选择视频 → 角色介绍 → 7秒试听 → 45秒试听 → 必要的短片复验 → 完整制作 → 播放与保存 → 再次收听。

## 2. 产品规则

### 无视觉操作

- 阶段变化说明当前位置、真实结果、下一步；不虚构百分比和完成状态。
- 标准键盘可完成所有操作。快捷键、按钮、语音反馈共用服务端操作与确认规则。
- 首次开声、系统文件选择、麦克风权限纳入使用路径；系统界面通过读屏操作。
- 用户明确选择站内引导或读屏优先，读屏优先停止重复播报。
- 提示、影片和录音互斥；打开反馈暂停影片，关闭后用户主动恢复。
- 弹窗约束焦点并在关闭后恢复；后台进度不抢焦点。
- 随时有停止提示、重听提示、播放暂停、返回入口。

### 少操作与确认

- 选文件后自动处理；取消选择不创建任务。
- 角色介绍可暂停、重听、主动继续，不要求用户核验看不见的事实。
- 明确反馈直接重做当前片段；含糊或不支持意见说明范围，不假称已修改。
- 播放结束不等于满意；不以强制听满制造障碍。
- 中样片返工后确认，再用同源其他合适片段复验；复验失败不能放行整片。
- 候选和确认设置分离；音频、设置、确认绑定版本，旧响应不得覆盖新版。
- 保存独立于确认；完成后不自动大声播放，保存不要求先看完整片。

### 内容与原声

- 称呼稳定、未知姓名用外观描述，不编造人物身份、不提前剧透。
- 旁白解释必要视觉信息，不重复对白，不覆盖重要原声。
- 调整只影响旁白，保留原片速度和原声音量；保留独立旁白轨及开关。
- 过长先精简、重配、检查，仍冲突则保留产物并报告问题。
- 整片覆盖原视频全长，不以试听片段拼接替代整片。

## 3. 实施顺序与接口

| 阶段 | 内容 | 出口 |
|---|---|---|
| P0 | 固定提交、文件摘要和检查基线 | 可追溯迁移记录 |
| P1 | 演示路径键盘、播报、焦点、恢复 | 无视觉正常与返工路径 |
| P2 | 真实上传、分析、角色、7秒与45秒 | 真实素材对应样片 |
| P3 | 录音转写、返工、版本、独立轨、整片续作 | 真实上传至保存回看 |
| P4 | 读屏、蒙眼走查、视障用户试用 | 指定环境独立完成任务 |

- Node 本地服务同源提供页面、业务接口和私有媒体；已有 Worker 演示构建保留。
- 保留上传、项目查询、分段操作、录音转写接口，前端统一适配。
- 服务端管理真实任务阶段、版本和请求标识，拒绝过期或重复操作。
- 结果包含角色、候选/确认设置、样片范围、产物版本、原片/旁白地址。
- 持久保存任务、已确认结果、已完成块和播放位置，重启可恢复。
- 将旧12秒与5分钟规则适配为7秒、45秒与全片；根据候选窗口选择试听位置，短素材显示真实范围。
- 视频理解和转写复用原处理能力；TTS 优先使用已有豆包协议，Node 使用独立传输适配。

### 豆包 TTS

- 附件是 Python 协议编解码和连接/会话辅助代码，不是完整配置或 ASR 服务；不执行附件。
- 复用仓库 JavaScript 协议；真实任务只合成服务端当前版本文本及支持的声音参数。
- 密钥仅服务端环境变量；不写入浏览器、文档、Git、日志。本轮按用户后续明确提供及授权的凭据接入本机服务，不从截图自行提取。
- 缓存按文本、影片、声音和语速隔离，取消终止等待，过期结果丢弃。
- 失败明确报告；只复用匹配版本的豆包缓存，不以旧音频代替修改结果。
- 后续用户明确要求全局消除机械提示音：按钮、引导和预览统一豆包，固定提示提前生成并本地保存；删除浏览器系统语音及旧提示音兜底。

## 4. 测试与完成标准

1. 首次进入至文件选择、角色、试听、保存、刷新回看，不看屏幕完成。
2. 7秒修改可听见，确认后45秒继承设置。
3. 45秒返工确认后必须新短片复验，不能绕过。
4. 麦克风拒绝、转写失败、意见不明可恢复；保留当前任务录音供重试。
5. 取消文件、媒体失败、网络/生成失败、重启可继续。
6. 重复确认、旧响应、刷新不导致重复任务或错误版本。
7. 原片和旁白独立控制，整片无缺段，原片速度不变。
8. 读屏无持续双重播报，弹窗无键盘陷阱。
9. 任意文件不套用预设人物和旁白。
10. 听者能理解主要人物事件；由能对照素材的人补充事实审查。

记录独立完成、求助、操作次数、等待及卡点。测试基线为新仓库16项、本地26项和语法检查通过，均为迁移前结果。模拟模型测试与真实媒体测试不等于真实模型生成验证；蒙眼测试不等于视障用户验收。未执行的项目明确留待验证，不编造成功率、时延或用户反馈。
