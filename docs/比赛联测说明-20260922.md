## 建议测试顺序

1. 首页 → 创建新视频 → 使用演示视频 → 人物介绍 → 首个场景。
2. 播放，确认视频与旁白能正常开始、暂停、重听。
3. 旁白助手输入“旁白慢一点” → 确认执行 → 试听新版 → 满意并继续。
4. 扩展到前 3 个场景，再生成整片；重点确认未修改场景的旁白是否保留。
5. 保存 → 顶部“我的视频” → 打开作品 → 刷新后重开，检查结果与观看进度。
6. 使用专门的测试视频走真实上传；记录失败发生的阶段、错误原文、是否能重试恢复。
7. 用键盘 Tab、Shift+Tab、Enter、空格和 Escape 检查操作；真人语音输入、实际麦克风和读屏另行测试。

建议反馈格式：测试时间 / 浏览器与设备 / 素材 / 操作步骤 / 预期 / 实际 / 截图或录屏。测试空间由团队共享，请用带测试标识的素材，不修改或删除他人项目。

## 已发现，尚未修复

| 编号 | 优先级 | 问题与复现提示 |
| --- | --- | --- |
| TJ-01 | P1 | 首场景修改并采用后，扩展/整片可能只剩首场景旁白。实测 184.2 秒成片旁白轨在第 10 秒后全为静音，原本 34.35、89.4、110.4 秒的旁白缺失；原片原声不在这个结论内。 |
| TJ-02 | P1 | 真实上传人物结果曾连续两次结构/依据失败；整片生成报“模型未给出有效的精简建议”，重试仍失败。 |
| TJ-03 | P1 | 真实配音生成成功后，左侧仍显示“模拟修改方案已就绪/查看模拟结果”。 |
| TJ-04 | P2 | “修改角色介绍”只提示先进入首个场景，没有角色编辑入口。 |
| TJ-05 | P2 | 保存后返回首页的“我的视频”只显示公开视频；新作品需从顶部“我的视频”进入全部视频查找。 |
| TJ-06 | P2 | 单次旁白修改请求约 76 秒，之后还需等待轮询；等待状态的解释和退路不足。此为单次实测，不是平均耗时。 |
| TJ-07 | P2 | 处理完成与试听页重复确认、阶段名称不一致，1366×768 下继续按钮可能落在首屏以下；粘贴链接只支持预设演示链接。 |
| TJ-08 | 待复核 | 重开作品曾出现媒体读取超时，重新加载后恢复。尚未定位为稳定复现的代码缺陷。 |
