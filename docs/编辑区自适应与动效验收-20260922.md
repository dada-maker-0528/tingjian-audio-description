## 动效

默认启用。采用原生 Web Animations API：侧栏宽高 300ms 连续变化、模式选中块 260ms 滑动、内容 220ms 轻移淡入、弹窗 240ms 渐入。移除展开按钮强制跳到页面顶部的行为。快速切换从当前动画位置继续，结束恢复自然尺寸。仅在操作系统明确开启减少动态效果时跳过动画。

比较来源：https://motion.dev/docs/animate 与 https://developer.mozilla.org/en-US/docs/Web/API/Web_Animations_API 。本次未新增第三方依赖。
