# 修订与提示词联动

入口：https://tingjian.43.129.168.70.sslip.io/ 。当前实现位于 tingjian-audio-description。

## 使用

1. 在样片或成片页打开“提交修订意见”。常用项可直接选择；更多调整按语音表现、描述详略、叙述重点、表达风格两级展开。
2. 标签仅修改草稿，不提交生成。文字或录音转写先通过“AI 整理修改意见”转为可审阅草稿；存在疑问时保留原草稿，显示确认提示。
3. 摘要显示参数变化和修改的提示词；技术详情可直接编辑实际提示词，比较修改前后内容。
4. 默认仅用于当前项目。选择同时更新提示词库时，额外显示相对当前库版本的差异。只修改本次改变的模板，保留其他模板，版本冲突会阻止提交。
5. 生成修订样片后保留原版结果，并沿用审校、复验和完整交付流程。

预设演示素材仅开放实际准备好的语速、音量、详略和音色，不假装采用改写后的旁白文本。人物纠错、指定某句话或指定时间段替换尚未提供；人物解析模板用于新项目，本次样片重制只采用编排与精简模板。

## 可核验的执行依据

- 工作空间模板保存版本历史；恢复旧版先进入编辑草稿，再保存为新版本，不覆盖历史。
- 项目冻结实际采用的完整模板快照、参数、模板基准版本及 SHA-256。项目修订内容和工作空间默认模板分离。
- 每次重制重新进行旁白编排。Doubao 语音缓存键加入提示词摘要，实际记录命中或新合成；其他提供方未报告时显示未报告，不推断缓存结果。
- 执行记录来自后端实际处理事件，包含尝试次数、起止时间、恢复分段、模型、参数与模板快照，可比较上一版旁白并播放旧版独立音轨。
- 旧任务没有的执行记录不补造；早期恢复分段缺少模板信息时明确标明。
- 保存模板、预览修改和执行生成分别有明确入口；AI 整理草稿不会直接保存或启动任务。
